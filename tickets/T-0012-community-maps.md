# Validate community maps before play

A shared map is data. It is checked before it becomes playable.

## Checks

- [ ] Schema with generator version.
- [ ] Connectivity and budget checks.
- [ ] Author and provenance fields.
- [ ] Rollback for a bad map.
- [ ] Per-map performance budget.
